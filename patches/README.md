# Патч понятности для живой ветки `arena/c55ca3f6` (v113)

Живой сайт (`https://alexquantforge.github.io/sanskrit-in-action/`) собирается
GitHub Pages **с ветки `arena/c55ca3f6-sanskrit-in-action`** (v113), а не с этой
ветки. На v113 **урок 8 — это «Цифры 1–5»** (`lesson4.js`, `num: 8`), и именно
там находятся три вещи, на которые жаловались:

1. **Упражнение 10 «Категории»** — название «Со слитным знаком ्» непонятно.
2. **Игра 22 «Слепое поле»** — непонятно, как играть.
3. **Игра 24 «Бинго»** — непонятно, как играть и нужно ли два устройства.

Правки сделаны и проверены в этой ветке (v58, коммит `2c3ca58`) **и** перенесены
на код v113:

* `clarity_v113.patch` — готовый unified diff (470 строк);
* `clarity_v113.py` — тот же патч «по якорям»: пригодится, если v113 уедет вперёд
  и diff перестанет прикладываться.

## Применение (на ветке `arena/c55ca3f6`)

```bash
# 1. взять патч из этой ветки
git fetch origin arena/10685d47-sanskrit-in-action
git show origin/arena/10685d47-sanskrit-in-action:patches/clarity_v113.patch > /tmp/clarity.patch

# 2. проверить и применить
git apply --check /tmp/clarity.patch && git apply /tmp/clarity.patch

# 3. проверить и запушить
node tests/regression.js     # ожидается ALL CHECKS PASSED, 2136 проверок
git commit -am "Понятность: категории, слепое поле, бинго (v114)"
git push
```

Если `git apply` не проходит (ветка уехала), запустите скрипт: он ищет каждый
участок по тексту и печатает `OK` / `MISS`, так что ничего не испортится молча:

```bash
git show origin/arena/10685d47-sanskrit-in-action:patches/clarity_v113.py > /tmp/clarity.py
python3 /tmp/clarity.py
```
